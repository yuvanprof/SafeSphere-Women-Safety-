Proposed stack & limitations

Mobile: React Native · AI: TensorFlow · Location: device GPS APIs · Backend: Firebase or equivalent · Fallback: compatible GSM/SMS hardware.

Safety design requirements: minimize collected data, obtain informed consent, secure location/audio, test false positives and missed detections, and never imply alert delivery is guaranteed. Browser geolocation generally requires permission and a secure context (HTTPS or localhost).
